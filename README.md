# SkillForge Social Media Content Plan

Prepared by **Tanya Chauhan**.

## How to run
Open `index.html` in any modern browser. No server is required.

## Project files
- `index.html` - website structure and content
- `styles.css` - layout, colors, responsive design
- `script.js` - mobile menu and dynamic schedule table
- `assets/workflow.png` - workflow picture
- `assets/hero.png` - hero banner image
- `docs/Theory.md` - explanation and presentation theory
- `docs/Project_Report.docx` - professional report

## Goal
Create a social media content plan with target audience, content ideas, posting schedule, sample posts, metrics, logbook, and workflow.
