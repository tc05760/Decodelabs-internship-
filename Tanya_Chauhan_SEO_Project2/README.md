# Tanya Chauhan - Digital Marketing Project 2

## Project Title
SEO Basics & Keyword Research

## How to Open
1. Extract this ZIP file.
2. Open `index.html` in any browser.
3. Open `docs/Project_Report.docx` or `docs/Project_Report.pdf` for the written report.
4. Open `presentation/Project2_SEO_Presentation.pptx` for the slide deck.

## Folder Structure
- `index.html` - Main website page.
- `css/styles.css` - Website styling.
- `js/script.js` - Beginner-friendly table filtering logic.
- `assets/seo-workflow.png` - Workflow picture.
- `assets/intent-map.png` - Search intent infographic.
- `data/keyword-research.csv` - Keyword research table.
- `data/keyword-research.json` - Keyword data for reuse.
- `docs/Project_Report.docx` - Editable report.
- `docs/Project_Report.pdf` - Submission-ready PDF.
- `presentation/Project2_SEO_Presentation.pptx` - Presentation file.

## Project Summary
This project explains how to perform basic keyword research, identify search intent, use long-tail keyword logic, calculate KGR, and suggest content topics for SEO growth.
